# AGENTS Documentation

## Overview
This document contains information about the AI agents in the Personal AI Employee system.

## Architecture
- The Brain: Claude Code acts as the reasoning engine
- The Memory/GUI: Obsidian (local Markdown) as the dashboard
- The Senses (Watchers): Lightweight Python scripts monitoring various inputs
- The Hands (MCP): Model Context Protocol (MCP) servers for external actions

## Agent Types
- Personal Affairs Manager (Gmail, WhatsApp, Banking)
- Business Operations Manager (Social Media, Payments, Project Tasks)
- CEO Briefing Agent (Revenue reporting and bottleneck identification)
